# Catalogue d'arômes (démo hackathon)

`catalogue_aromes.csv` est un catalogue **fictif** de 48 arômes alimentaires créé pour la
démo du hackathon. Il ne contient **aucune donnée réelle Givaudan**.

Format : UTF-8, séparateur `;`.

| Colonne | Description |
|---------|-------------|
| `id` | Identifiant unique de l'arôme (AR001 à AR048) |
| `nom` | Nom commercial de l'arôme |
| `famille` | Famille aromatique (Fruité rouge, Agrumes, Épicé, Salé…) |
| `description` | Description du profil aromatique en une phrase |
| `notes_gout` | Notes de goût principales, séparées par des virgules |
| `applications` | Produits dans lesquels l'arôme est conseillé |
| `forme` | Forme physique : `liquide` ou `poudre` |
| `dosage_conseille` | Dosage conseillé dans le produit fini |
| `certifications` | Certifications : naturel, vegan, halal (selon l'arôme) |
| `prix_indicatif_eur_kg` | Prix indicatif en euros par kilo |
| `quantite_min_kg` | Quantité minimale de commande en kilos |
